# Rhetoric Analysis

## Status

Partially implemented. The legacy English discourse method records simple
lexical observations and exact supporting spans. It is not a general rhetoric,
framing, sentiment, propaganda, or intent detector.

## Intended boundary

Future rhetoric analysis should represent separate measurable dimensions,
such as:

- certainty and hedging;
- attribution and evidential language;
- emotional intensity;
- evaluative labels;
- agency assignment;
- quotation balance;
- headline/body differences;
- changes through time and across document versions.

Each observation must reference exact source text and a versioned method.
Cross-source comparisons must control for language, genre, article length,
quoted speakers, and boilerplate. A rhetorical feature describes communication;
it does not by itself establish deception, propaganda, intent, or falsity.

See [Discourse Analysis](discourse_analysis.md) for the current implementation.
